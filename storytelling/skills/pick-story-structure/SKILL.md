# Pick Story Structure
<!-- scaffold: T2, the pick-ui-library analogue — codified taste in which shape to reach for. -->

## Inherits
- philosophy.md question 5; story-shapes.md

## The menu
- Reagan's six arcs with the design-story default for each [R]
- Sparkline (what is / what could be) for vision
- SCQA for argument
- Zoom-in / zoom-out (house shape)
- Story Spine as the shape-agnostic scaffold

## Selection rules
- Inputs: material type (case / vision / argument / postmortem / culture) · audience (exec / peer / panel) · time (60s / 5 min / 8–10 min / 30 min)
- Decision table, one row per combination, with the recommended shape and why
- Anti-recommendations: hero's journey for a case study (makes the presenter the hero) · three acts when the time is under 5 min

## Output format (required)
- Shape name · why this one · the two it beat and why · the beat count the shape implies at this length
