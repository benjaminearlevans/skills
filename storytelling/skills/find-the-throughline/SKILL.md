# Find the Throughline
<!-- scaffold: T2, build FIRST — this is Benjamin's recurring problem. High freedom: judgment, not template. -->

## Inherits
- philosophy.md — principles 2 (contrast), 3 (throughline outranks ideas), 10 (compression)

## The test
- Can the whole thing be stated as one ABT sentence? *[Setup] AND [context], BUT [tension], THEREFORE [resolution].* If not, the throughline isn't found yet [P, Olson]
- Diagnosis of what's wrong when it fails: AAA (list, no tension) or DHY (all tension, no line)

## Procedure
1. Inventory every idea as a one-line card — no editing yet
2. Ask the five questions (philosophy.md); answer 2 ("the one belief") before anything else
3. Draft three rival ABT sentences, not one — force a choice
4. For the chosen ABT: sort every card into *carries the line* / *supports a beat* / *footnote* / *cut* — every card gets a bin, none float
5. Name the hinge (McKee's turning point) — the card where the "BUT" turns into the "THEREFORE"
6. Output

## Output format (required)
- The throughline as one ABT sentence
- The hinge, named
- Four bins with every card assigned
- One line: what the person will lose by cutting the "cut" bin, stated plainly so the loss is a decision not an accident

## Why this works
- Cognitive load: audiences hold ~4 chunks; the bins force the author to do the compression the audience can't [R, Sweller]
- Curse of knowledge: the author sees connections the audience won't; the ABT test is an outside view [R]
