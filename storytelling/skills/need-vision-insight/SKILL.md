# Need → Vision → Insight
<!-- scaffold: T2, medium freedom. Benjamin's own framework, given its lineage. -->

## Inherits
- philosophy.md; executive-forms.md

## Backbone
- Monroe's Motivated Sequence: Attention → Need → Satisfaction → Visualization → Action [P, 1935], with the label mapping: Need = customer need · Satisfaction = the design bet · Visualization = the vision · Action = the business ask
- Amazon PR/FAQ as the "working backwards" lineage — write the customer's press release first [P]

## Step rules and failure modes
- Need: stated as one specific person's situation, not a segment [R, identifiable victim]; failure = abstract need
- Vision: a state of the world, not a feature list; contrast against "what is" [P, Duarte]; failure = roadmap disguised as vision
- Insight: the business number threaded through, translated to human scale [P, Heath & Starr]; failure = bolted on at the end
- Ask: one specific decision the room can make today; failure = "thoughts?"

## Output format (required)
- Five labelled sections, each ≤ 3 sentences plus one receipt
- The ABT sentence at the top (from find-the-throughline)
