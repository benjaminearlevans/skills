## Dominant narrative forms in this domain
- Design doc (context → goals/non-goals → design → alternatives → cross-cutting concerns)
- Blameless postmortem (timeline → root cause → what went well/wrong → actions) — fall-rise shape
- Amazon-style narrative memo

## Named failure modes
- Alternatives considered omitted · timeline without causation · "what we did" instead of "what we learned"
