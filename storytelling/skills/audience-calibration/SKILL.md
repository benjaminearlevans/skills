# Audience Calibration
<!-- scaffold: T2. Executive mode fully specified first; other modes are stubs. -->

## Inherits
- philosophy.md question 1 (who, and what do they already believe); executive-forms.md

## Executive mode (build first)
- SCQA as the required opening; answer in the first sentence [P, Minto]
- Pyramid: one claim, grouped support, MECE
- Receipts on standby, not on the slide
- Compression targets: state a number (e.g., "the ask in 60 seconds, the whole thing in 5 minutes")
- Failure modes: context before conclusion · options without a recommendation · process narrative

## Peer / critique mode (stub)
- Spencer: set context, state the goal, show work in argument order, ask for the specific feedback you need [P]

## Hiring-panel mode (stub)
- Defer to the existing hiring-panel-review skill; this mode only prepares the narrative for it

## Q&A mode (stub)
- What / So What / Now What as the answer shape [P, Abrahams]; the "held for Q&A" list from narrate's ⚠ flags

## Output format (required)
- The calibrated narrative + a diff list: what moved, what was cut, what went to standby
