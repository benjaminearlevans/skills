# Review Narrative
<!-- scaffold: T2, the review-animations analogue. Low freedom on the output format, high freedom on judgment. -->

## Inherits
- philosophy.md — every principle is a check

## Checks (each with its why)
- ABT test passes; not AAA, not DHY [Olson]
- Hinge present and named [McKee]
- Every beat flips a value [McKee]
- Ethos / pathos / logos — which leg is missing [Aristotle]
- SUCCESs pass: simple · unexpected · concrete · credible · emotional · story [Heath]
- Numbers: one locked figure per claim, human-scale translation present, no two conflicting stats [Heath & Starr; Benjamin's lock rule]
- Bad news first, never buried
- Close is a receipt, not a recap [peak–end]
- Receipts: every claim has one or a ⚠
- Curse-of-knowledge scan: what does the author know that the audience doesn't [Newton 1990]

## Output format (required, mandated like emil's Before/After/Why)
- One markdown table: **Line → Problem → Fix → Why** — one row per issue
- Explicit "wrong format, never do this" example
- Verdict line: pass / revise / restructure, with the single highest-leverage fix named
- Tone: analysis not reaction (Connor & Irizarry)
