<!-- scaffold: T2, medium freedom — template with judgment inside the slots. Absorbs case-study-creator + bxn-storyboard conventions. -->

## Inherits
- philosophy.md; a throughline from find-the-throughline (require it — if absent, run that skill first)

## Scaffold
- Story Spine as the drafting skeleton: once upon a time / every day / until one day / because of that ×N / until finally / ever since [P, Adams/Pixar] — mapped onto Benjamin's beat names: promise/break → trap → hinge/bet → method → proof → receipts → miss/close
- Zoom-in / zoom-out as the house move: one proof point deep, then scale (story-shapes.md)

## Beat rules
- Opening beat opens a gap, never sets context [R, Loewenstein]
- One person before the number [R, identifiable victim]
- Every beat flips a value (McKee) — no value change, no beat
- One STAR moment, placed deliberately [P, Duarte]
- Close is a locked receipt, never a recap [R, peak–end]
- Every claim carries a receipt or a ⚠ flag — flags are output, not hidden

## Output format (required)
- Numbered beats, each: eyebrow · sticky title · three bullets · receipt or ⚠ · value flipped (from → to)
- Word/time estimate per beat against the delivery constraint (e.g., 8 min per case)
