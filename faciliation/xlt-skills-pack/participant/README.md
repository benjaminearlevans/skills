# XLT Pre-work

A short interview, run by Claude on your computer, that captures your team's tooling, problems and outcomes before the XLT session. That way we spend the session deciding, not collecting.

## Install (one step)

Open Terminal in this folder and run:

```
bash install.sh
```

This copies three skills (`xlt-prework`, `facilitating`, `outcome-modeling`) into `~/.claude/skills/`. Nothing else is changed.

**Prefer to do it by hand?** Move those three folders into `~/.claude/skills/` yourself.

## Run

Open Claude Code (any folder) and type:

```
/xlt-prework
```

- It takes about 15 minutes, longer if you have more to say.
- You can stop at any time. Run `/xlt-prework` again to pick up where you left off.
- People's names are replaced with roles automatically.
- Nothing leaves your computer.

## Submit

When you finish, the interview creates a folder at `~/xlt-prework/<your-team>/`. Drop that whole folder into the shared drive link the interview gives you, by the deadline it tells you.

## Help

Contact the person named in the pre-work email.
